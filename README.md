# 📊 Data Manipulation Using Pandas

## 📌 Project Overview

This project is a web application developed using **Python**, **Pandas**, and **Streamlit** to perform data manipulation and analysis on CSV datasets. It allows users to upload a CSV file, explore the data, generate summary statistics, filter records, visualize information, and download the processed dataset.

The application provides an easy-to-use interface for performing basic data analysis without writing Python code.

---

## 🎯 Problem Statement

Analyzing large datasets manually is time-consuming and prone to errors. Users often need a simple tool to upload datasets, inspect data, perform filtering, visualize trends, and generate useful insights.

This project solves that problem by providing an interactive web application that performs data manipulation using the Pandas library.

---

## ✨ Features

- Upload CSV files
- Display dataset preview
- View dataset information
- Display summary statistics
- Check missing values
- Detect duplicate records
- Filter dataset interactively
- Generate data visualizations
- Download filtered dataset

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/fiz679/data-manipulation.git
```

Move into the project directory

```bash
cd data-manipulation
```

Create a virtual environment

```bash
python -m venv venv
```

Activate the virtual environment

**Windows**

```bash
venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
